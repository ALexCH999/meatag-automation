# Обработка продаж по артикулам

Скрипт агрегирует заказы из `sales.csv` по артикулу и дате. Отменённые заказы входят в `orders`, но не в `revenue`. Один `order_id` учитывается один раз.

## Запуск

Нужен Python 3. Внешние библиотеки устанавливать не нужно: используются только модули стандартной библиотеки.

Положите `sales.csv` рядом с `process_sales.py` и из этой папки выполните:

```bash
python3 process_sales.py
```

Скрипт создаст или перезапишет `daily_by_sku.csv` в той же папке.

## Проверка результата

Для независимой проверки запустите:

```bash
python3 check.py
```

`check.py` заново читает `sales.csv`, оставляет по одному вхождению каждого `order_id`, нормализует статусы и пересчитывает показатели по артикулу и дате. Затем он сравнивает заголовки и все строки с `daily_by_sku.csv`; при расхождении сообщает номер первой отличающейся строки. Проверка использует только стандартную библиотеку Python, устанавливать зависимости не нужно.

На предоставленной выгрузке проверка завершилась сообщением `OK`: совпали все 631 строка. Контрольные суммы: 13 798 учтённых заказов, сумма `orders` — 13 798, общая выручка — 10 276 540 рублей.

## Особенности исходных данных

- Нашлось 60 повторных строк с уже встречавшимся `order_id`. Все повторы в этой выгрузке полностью совпадают с исходными строками; повторные вхождения не учитываются.
- Статусы встречаются в разном регистре, а также есть вариант `canceled`. Скрипт приводит статусы к нижнему регистру и нормализует `canceled` в `cancelled`.
- У четырёх отменённых заказов пустое `quantity`. Они остаются в подсчёте заказов; скрипт читает количество и цену только для `delivered`, поэтому пропуски не влияют на выручку.

## Ограничения и недоделки

Если одинаковый `order_id` встретится с разными данными, скрипт оставит первое вхождение без предупреждения. Скрипт также ожидает корректные заголовки и числовые `quantity` и `price` у заказов со статусом `delivered`; пустое или нечисловое значение приведёт к ошибке. В проверенной выгрузке конфликтующих дублей и пропусков в данных выкупленных заказов не обнаружено. Других известных недоделок нет.
